# LifeMode Premium Design System

LifeMode should feel calm, useful, trustworthy, and personal. It should not feel like a noisy social media app or a generic AI dashboard.

## Design Personality

Words:

- calm
- premium
- disciplined
- human
- focused
- safe
- modern

Avoid:

- childish colors
- cluttered feeds
- too many badges
- loud gradients
- huge marketing sections inside the app
- confusing icons without labels
- dark-only design

## Layout Rules

Phone:

- One main action per section.
- Large tap targets.
- Clear spacing between cards.
- Sticky top app bar only if it helps navigation.
- Dashboard sections stacked in priority order.

Tablet:

- Two-column dashboard.
- Left side for goals/proof.
- Right side for AI Buddy, opportunities, and safety.

Laptop:

- Dense but calm dashboard.
- Metrics row at top.
- Main work panels below.
- Avoid empty decoration.

## Core Screens

### Auth

Signup and login should feel serious and trustworthy.

Needed:

- Clear LifeMode brand
- Short promise
- Email/password
- Mode choice on signup
- Safety note for 18+ dating

### Dashboard

The dashboard should be the app's home.

Needed:

- Mode selector
- Today's goals
- Proof timeline
- Mode tools
- Opportunities
- Connect settings
- AI Buddy

### Profile

The profile should show proof, not just claims.

Needed:

- Name
- Active mode
- Skills
- Proof posts
- Streaks
- Opportunities/applications
- Public/private controls

### Opportunities

Opportunities should feel more like a serious career tool than a feed.

Needed:

- Save
- Apply
- Notes
- Deadline
- Company/source
- Verified status
- Mode fit

### Connect

Connect should feel controlled and safe.

Needed:

- Intent settings
- Age-gated dating
- Respect Lock
- Block/report
- No exact location by default

## Visual Direction

Base colors:

- Background: warm off-white
- Text: near-black
- Accent: warm brown
- Success: soft green
- Info: soft blue
- Safety/dark panels: near-black

Component style:

- Border radius: 8px or less
- Soft borders
- Minimal shadows
- Clear active states
- No nested cards inside cards
- No decorative blobs

Typography:

- Strong headings
- Readable body text
- No tiny important labels
- No viewport-scaled font sizes
- No negative letter spacing

## Interaction Rules

Every main section should have a useful action:

- Goals: add, complete, delete, clear completed
- Proof: add, remove
- Opportunities: save, apply, track
- Connect: toggle intents, check rules, Respect Lock
- AI Buddy: ask, save history
- Modes: switch and adapt the dashboard

Feedback:

- Show loading states.
- Show empty states.
- Show saved states.
- Show blocked/safety messages clearly.

## Premium Upgrade Path

First polish pass:

- Clean mobile spacing.
- Better top navigation.
- Better button hierarchy.
- Better form states.
- Better empty states.

Second polish pass:

- Dedicated profile page.
- Dedicated opportunities page.
- Settings page.
- Admin page.
- Responsive tablet layouts.

Third polish pass:

- Subtle transitions.
- Skeleton loading.
- Better PWA icon set.
- Improved onboarding.
