# LifeMode Release Roadmap

This roadmap has two parts:

1. Big launch milestones.
2. Small post-launch updates where each update adds one major feature.

Proof Profile and Opportunity Tracker are launch features. They are part of the main attraction, not future add-ons.

## Milestone 1: Private Beta

Goal:

Release LifeMode to a small group of testers.

Purpose:

Check whether people understand the product, use the dashboard, build proof, and track real opportunities.

Included features:

- Signup, login, logout, and protected dashboard.
- Mode selector for Student, Gym, Career, Business, Law, and Creator.
- Mode-based daily goals.
- Goal completion, deletion, and clear completed action.
- Proof timeline with add/remove proof posts.
- Proof Profile with bio, skills, proof score, recent proof, and public/private toggle.
- Opportunity Tracker with saved/applied status, notes, deadline, and follow-up date.
- AI Buddy starter plans by mode.
- Opportunities list filtered by mode.
- Connection preferences with mode-based safety checks.
- Vibe Alerts toggle and Respect Lock simulation.
- Installable web app/PWA support.

Supported devices:

- Laptop browser
- Phone browser
- Tablet browser
- Installable web app through browser home screen

Before Private Beta is ready:

- Move user dashboard data from local storage to Supabase tables.
- Make the design feel premium on phone and laptop.
- Fix obvious bugs.

## Milestone 2: Public Beta

Goal:

Open LifeMode to more users without calling it the final app yet.

Purpose:

Test real usage, retention, safety, proof profiles, and opportunity tracking.

Included improvements:

- Better onboarding.
- Improved Proof Profile.
- Improved Opportunity Tracker.
- Settings page.
- Better mobile navigation.
- Better empty states and loading states.
- Basic feedback/report issue flow.
- Stronger safety messaging.

Before Public Beta is ready:

- Users should be able to use the app without you explaining every step.
- Core data should sync across devices.
- Safety controls should be clear.
- Proof Profile and Opportunity Tracker should feel like the main reason to use the app.

## Milestone 3: App Launch

Goal:

Release LifeMode publicly as the first official app version.

Purpose:

Make the product stable enough to share widely.

Included improvements:

- Public landing page.
- Terms, privacy, and safety pages.
- Production deployment.
- Custom domain.
- Basic analytics.
- Polished dashboard design.
- Stable authentication and database.

Launch rule:

The first official launch should be a web/PWA app. Native phone apps come after the web app proves people want to use it.

## Post-Launch Update 1: Finance Tracker

Feature added:

Finance Tracker.

What it does:

Users can track their money inside the same life operating system.

Included:

- Add income.
- Add expense.
- Expense categories.
- Monthly budget.
- Savings goal.
- Spending summary.
- Recent transactions.
- Notes for each transaction.

Why this is the first update:

Money is part of real life progress. If LifeMode helps users build skills, find opportunities, and manage money, it becomes more useful every week.

Success test:

Users should be able to say: "LifeMode helps me understand where my money is going."

## Post-Launch Update 2: Payments Layer

Feature added:

Payments Layer.

What it does:

Users can connect payments to the finance system when the app is ready for regulated payment features.

Included:

- UPI payment planning for supported regions.
- Tap-to-pay planning for supported devices.
- Payment history.
- Payment notes.
- Payment linked to expense tracking.
- Strong security and consent screens.

Important:

Payments are regulated. This feature must use approved payment providers and follow legal, banking, and app store rules. It should not be built casually.

Why this is the second update:

Expense tracking is useful, but payments make the finance system more powerful. The app can move from "recording money" to "helping users act with money."

Success test:

Users should be able to make or record a payment and see it automatically reflected in their finance tracker.

## Later Updates

After the first two updates, each update should add one major feature.

Possible update order:

1. Partner Requests
2. Respect Lock Enforcement
3. Company Submission Form
4. Admin Opportunity Review
5. Weekly AI Buddy Review
6. Notifications
7. Shareable Profile Link
8. Public Discovery
9. Native Phone App
10. Tablet Layout
11. Watch Quick Actions
12. Advanced Finance Insights

Rule:

Do not add too many features in one update. Users should understand what changed.

## Opportunities Partnership Ladder

Do not depend on a large external platform at the beginning.

Order:

1. Manual opportunities in the app.
2. Admin-added opportunities.
3. Company submission form.
4. Small startups and local businesses.
5. Colleges, gyms, coaching centers, and creator teams.
6. Larger companies.
7. Job boards and platforms.
8. Major platform partnerships only after traction.

Reason:

Large companies usually do not partner with an app before it has users, proof, and a clear advantage.
